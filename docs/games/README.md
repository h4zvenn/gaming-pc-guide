## Testing

Use the same game version, settings, scene, and measurement method before and after every change.

See [Benchmark Templates](../16-benchmark-templates.html) for the full testing protocol.

## Safety

- Do not use cheats, injectors, or unapproved third-party software.
- Do not modify game files.
- Check anti-cheat and server rules before installing mods.
- Change one setting at a time.
- Keep a rollback path for every change.
