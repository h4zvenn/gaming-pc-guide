## Before you change anything

1. Create a restore point (see [Before you start](01-before-you-start.html)).
2. Record the game, scene, settings, FPS, frame-time results, and temperatures.
3. Change only one setting that relates to the observed symptom.
4. Repeat the same test and keep the change only if the result is measurable and stable.

For the full measurement process, use [Benchmark templates](16-benchmark-templates.html). To browse everything, see [All guides](index.html).

## Safety

- Do not disable Defender, Firewall, Windows Update, or anti-cheat protections to improve FPS.
- Do not run unknown debloat, registry cleaner, "RAM booster", or "FPS boost" scripts.
- Keep a rollback path before changing drivers, BIOS settings, or tuning values.
