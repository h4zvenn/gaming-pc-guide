## ✨ What is this?

An open-source, evidence-based guide to optimizing gaming PCs. It covers desktops and gaming laptops, NVIDIA, AMD and Intel hardware, and several popular games. This repository holds the source of the [guide website](https://h4zvenn.github.io/gaming-pc-optimization-guide/): step-by-step guides, benchmark templates, per-game pages and a read-only diagnostics tool.

Most "FPS boost" advice is copied from forum to forum and never tested. This project does the opposite: every change has to be measurable, reversible and labeled by what it applies to (OS, vendor or game).

### The method

1. **Find** the actual bottleneck.
2. **Change** one setting at a time.
3. **Benchmark** before and after.
4. **Keep** changes that help.
5. **Roll back** changes that do not.

> [!IMPORTANT]
> No "FPS boost" scripts. No mass service disabling. No universal BIOS presets.

## 🛠️ Diagnostics tool

A read-only Windows diagnostics menu is available in the `tools` folder. It is also attached to each release as a zip with a checksum.

### What it does

- ✅ Never changes any settings.
- 📄 Lets you export selected sections to a local report after you review the data notice and confirm.
- 🔒 Reports are not uploaded anywhere.

> [!WARNING]
> Before sharing a report, check it for device names, network details, usernames, startup commands, and file paths.

### Verify the download

```powershell
Get-FileHash .\gaming-diagnostics.zip -Algorithm SHA256
```

Compare the result with the checksum published in the release notes.

## ❓ FAQ

<details>
<summary><b>Will this void my warranty or break my PC?</b></summary>

<br>

The guide focuses on reversible changes and always describes a rollback path. Still, create a restore point first (see [Before You Start](https://h4zvenn.github.io/gaming-pc-optimization-guide/docs/01-before-you-start.html)).

</details>

<details>
<summary><b>Do I need to follow every step?</b></summary>

<br>

No. Diagnose first, then apply only what matches your bottleneck.

</details>

<details>
<summary><b>Is Windows 10 supported?</b></summary>

<br>

Only as a legacy platform. See [Windows 10 Legacy Notes](https://h4zvenn.github.io/gaming-pc-optimization-guide/docs/windows-10-legacy.html).

</details>

## 🤝 Contributing

Contributions are welcome: fixes, new game guides, translations, and benchmark data.

### How to contribute

1. Fork the repository.
2. Create a branch:

   ```bash
   git checkout -b feature/my-change
   ```

3. Make your changes and include evidence (benchmarks, sources, screenshots).
4. Open a pull request.

### Guidelines

- 📏 One claim, one source or one measurement.
- 🏷️ Label vendor-, OS-, and game-specific advice.
- 🚫 No "magic" tweaks without before/after results.

Found a mistake? [Open an issue](https://github.com/h4zvenn/gaming-pc-optimization-guide/issues).
