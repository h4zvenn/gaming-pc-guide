# Ultimate PC Gaming Optimization Guide 2026

A universal, evidence-based guide to diagnosing gaming PC issues across hardware, games, and Windows versions.

## Overview

This documentation provides a systematic approach to optimizing PC gaming performance. The methodology focuses on:

1. **Record** - Game, scene, settings, FPS, frame time, temperatures
2. **Change one setting** - Only a setting relevant to the bottleneck  
3. **Measure** - Result of the change
