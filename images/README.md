# Images Guidelines

Use this folder for visuals used in `README.md` and `docs/*.md`.

## Recommended formats

- `webp` (preferred for screenshots)
- `png` (for UI screenshots with text)
- `svg` (for diagrams/icons)

## Naming convention

Use lowercase kebab-case:

- `quick-start-flow.webp`
- `fps-before-after-table.png`
- `troubleshooting-tree-gpu.svg`

## Size and quality

- Keep width around `1200-1600px` for screenshots.
- Compress before commit.
- Prefer files under `500 KB` where possible.

## Content rules

- No personal/private data in screenshots.
- Blur usernames, serials, tokens, IPs, emails if present.
- Keep visuals practical: one image = one point.

## Markdown usage example

```markdown
Example (file may not exist yet): markdown image link to quick-start-flow.webp
```
