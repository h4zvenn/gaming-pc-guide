> Не начинай с массового отключения служб и процессов.
> Сначала посмотри, что реально запускается вместе с Windows и что использует CPU, диск или сеть во время игры.

## Что вы узнаете

- Как проверить автозагрузку.
- Как понять, какие приложения нагружают систему.
- Как безопасно отключить ненужный автозапуск.
- Как вернуть приложение, если оно понадобилось.

## Перед изменениями

Создай точку восстановления или хотя бы запиши, какие программы ты планируешь отключить.

Не отключай:

- Антивирус и защиту Windows.
- Драйверы видеокарты и периферии.
- Аудиосервисы.
- Сетевые службы.
- Системные обновления без понимания последствий.

## 1. Проверь автозагрузку через Диспетчер задач

Это самый безопасный способ.

1. Нажми `Ctrl + Shift + Esc`.
2. Открой вкладку `Автозагрузка приложений`.
3. Посмотри столбцы `Состояние` и `Влияние на запуск`.
4. Отключай только те приложения, которые не нужны сразу после включения ПК.

Хорошие кандидаты на отключение:

- Discord.
- Epic Games Launcher.
- Riot Client.
- Roblox.
- Spotify.
- Облачные клиенты, если синхронизация не нужна постоянно.

Не отключай без необходимости:

- Steam, если ты играешь каждый день.
- NVIDIA App или AMD Software.
- Logitech G HUB, Razer Synapse и другое ПО периферии.
- Антивирус.

## 2. Проверь автозагрузку через PowerShell

Скрипт ниже только показывает элементы автозагрузки. Он ничего не удаляет.

```powershell
Write-Host "`n===== АВТОЗАГРУЗКА ====="

Write-Host "`n--- Реестр текущего пользователя ---"
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -ErrorAction SilentlyContinue |
    Select-Object * -ExcludeProperty PS* |
    Format-List

Write-Host "`n--- Команды автозагрузки WMI ---"
Get-CimInstance Win32_StartupCommand |
    Select-Object Name, Command, Location |
    Format-List

Write-Host "`n--- Папка автозагрузки ---"
Get-ChildItem "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup" -ErrorAction SilentlyContinue |
    Select-Object Name, FullName |
    Format-List
```

### Что означают результаты

- `HKCU` — автозагрузка текущего пользователя.
- `Win32_StartupCommand` — общая информация о командах автозапуска.
- Папка `Startup` — ярлыки программ, запускаемых при входе в Windows.

## 3. Отключи ненужные приложения

Скрипт удаляет только записи автозапуска из реестра текущего пользователя. Сами программы остаются установленными.

Перед запуском проверь список `$disable` и оставь только те приложения, которые действительно не нужны в автозагрузке.

```powershell
$run = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run'

$disable = @(
    'Discord',
    'RiotClient',
    'RobloxPlayerBeta'
    # 'Steam',
    # 'LGHUB'
)

foreach ($name in $disable) {
    if (Get-ItemProperty -Path $run -Name $name -ErrorAction SilentlyContinue) {
        Remove-ItemProperty -Path $run -Name $name
        Write-Host "ОТКЛЮЧЕНО: $name"
    }
    else {
        Write-Host "НЕ НАЙДЕНО: $name"
    }
}
```

### Рекомендации

| Приложение | Рекомендация |
| --- | --- |
| Discord | Отключить автозапуск, если не нужен сразу |
| Riot Client | Отключить, если не играешь в игры Riot ежедневно |
| Roblox | Отключить автозапуск |
| Steam | По желанию |
| Epic Games Launcher | Отключить, если не нужен постоянно |
| Spotify | Отключить, если не нужен сразу |
| Logitech G HUB | Обычно не отключать |
| NVIDIA App | Не отключать |
| AMD Software | Не отключать |
| Антивирус | Не отключать |

## 4. Проверь фоновую активность во время игры

Автозагрузка — не единственный источник нагрузки. Во время игры проверь Диспетчер задач.

### Что смотреть

1. Открой `Ctrl + Shift + Esc`.
2. Перейди в `Процессы`.
3. Отсортируй по `ЦП`, `Память` и `Диск`.
4. Запусти игру и посмотри, какие процессы создают нагрузку.

### Частые источники нагрузки

- Браузер с большим количеством вкладок.
- Обновления Steam, Epic Games, Windows.
- Облачная синхронизация.
- Загрузка игр или модов.
- Стриминг и запись экрана.
- Антивирусная проверка.

---

## 5. Проверь результат

После отключения автозагрузки перезагрузи ПК и сравни:

- Время загрузки Windows.
- Количество фоновых процессов.
- Загрузку CPU и диска сразу после запуска.
- FPS и время кадра в игре.

Повтори тот же тест, что и до изменений.

---

## Как вернуть приложение

Открой приложение вручную и включи автозапуск в его настройках.

Например:

- Discord: `Настройки` → `Настройки приложения` → `Запускать Discord при включении компьютера`.
- Steam: `Steam` → `Настройки` → `Интерфейс` → `Запускать Steam при запуске компьютера`.
- Riot Client: включи соответствующую опцию в настройках клиента.
