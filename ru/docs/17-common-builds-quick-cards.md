> Начни быстро с безопасных значений по умолчанию. Затем проводи бенчмарки и настраивай каждую игру отдельно.

## Как пользоваться карточками

1. Выбери карточку своей платформы.
2. Применяй только базовые настройки.
3. Проведи бенчмарк по [шаблонам бенчмарка](16-benchmark-templates.html).
4. Настраивай по одному параметру.

---

## Карточка NVIDIA

### Базовые настройки

| Область | Рекомендуемый старт |
| --- | --- |
| Windows | Игровой режим включён, верная частота обновления, чистая автозагрузка |
| Драйвер | Стабильный драйвер Game Ready или Studio в зависимости от задач |
| В игре | Сначала настрой графику, затем лимит FPS |
| Задержка | Предпочитай внутриигровой NVIDIA Reflex, если он доступен |
| Синхронизация | Настраивай VRR и V-Sync для каждой игры |

### Первые пять изменений для проверки

1. Смени режим DLSS с Quality на Balanced.
2. Установи лимит FPS около стабильного минимального FPS.
3. Отключи лишние оверлеи.
4. Проверь HAGS включённым и выключенным.
5. При необходимости задай для игры режим питания `Prefer maximum performance`.

### Чего избегать по умолчанию

- Глобального принудительного Low Latency Mode для всех приложений.
- Глобального режима максимальной производительности для работы в рабочем столе.
- Случайных твиков реестра или BCD.

## Карточка AMD

### Базовые настройки

| Область | Рекомендуемый старт |
| --- | --- |
| Windows | Игровой режим включён, верная частота обновления, чистая автозагрузка |
| Драйвер | Стабильный релиз Adrenalin |
| В игре | Сначала настрой графику, затем лимит FPS |
| Задержка | Сначала попробуй внутриигровую опцию, затем Anti-Lag |
| Синхронизация | Настрой FreeSync/VRR и ограничение кадров |

### Первые пять изменений для проверки

1. Смени FSR или XeSS, если они доступны, с Quality на Balanced.
2. Включи Anti-Lag в профиле игры.
3. Установи лимит FPS для стабильного времени кадров.
4. Проверь Enhanced Sync на своём мониторе.
5. Убери наложение нескольких оверлеев.

### Чего избегать по умолчанию

- Одновременного включения Anti-Lag, Chill и нескольких настроек синхронизации.
- Слепого копирования кривых андервольтинга у других пользователей.

## Карточка Intel Arc и iGPU

### Базовые настройки

| Область | Рекомендуемый старт |
| --- | --- |
| Windows | Игровой режим включён, назначена высокопроизводительная GPU |
| Драйвер | Последний стабильный графический драйвер Intel |
| API | Проверь DX11, DX12 и Vulkan, если игра их поддерживает |
| В игре | Консервативные настройки и стабильный лимит FPS |
| Ноутбук | Питание от сети и профиль производительности производителя |

### Первые пять изменений для проверки

1. Переключай API между DX11, DX12 и Vulkan.
2. Смени режим внутриигрового апскейлера.
3. Установи лимит FPS для стабильности.
4. Очисти фоновые приложения.
5. Минимизируй оверлеи.

### Чего избегать по умолчанию

- Множества системных изменений до проверки API и поведения драйвера.
- Предположения, что один API всегда лучший для каждой игры.

## Быстрый выбор

| Цель | С чего начать |
| --- | --- |
| Быстро больше FPS | Снизь настройки, нагружающие GPU, используй апскейлер и лимит FPS |
| Больше плавности | Улучши 1% минимумов очисткой фона и охлаждением |
| Меньше воспринимаемая задержка | Используй внутриигровую технологию задержки и стабильный диапазон FPS |
| Больше стабильности | Вернись к штатным частотам, проверь драйверы и ошибки WHEA |

---

## Чек-лист проверки

- [ ] Используется одна и та же тестовая сцена до и после.
- [ ] Отслеживаются средний FPS, 1% минимумов и время кадров.
- [ ] Не появились новые сбои, ошибки WHEA или артефакты.
- [ ] Оставлены только измеримые улучшения.
