Цель настройки Windows — сократить реальную фоновую нагрузку, выбрать подходящие игровые параметры и сохранить стабильность и безопасность системы. Не нужно отключать десятки служб, Defender или обновления ради сомнительных «FPS-твиков».

## Принципы

- Меняй настройки по одной.
- Перезагружай ПК после крупных изменений.
- Проверяй FPS, 1% low, время кадра и стабильность.
- Оставляй только изменения с измеримым результатом или полезные для удобства.

## Пятиминутная проверка перед игрой

| Проверка | Целевое состояние |
| --- | --- |
| Игровой режим | Включён |
| Частота обновления монитора | Максимальное стабильное значение |
| Автозагрузка | Ненужные приложения отключены |
| Оверлеи | Оставлены только необходимые |
| Загрузки и обновления | Приостановлены на время игры |

> **Важно:** Windows не становится быстрее от отключения большего числа функций. Стабильная система с правильными драйверами и минимальной тяжёлой фоновой нагрузкой лучше агрессивной очистки.

## Игровой режим

Открой:

```text
Параметры → Игры → Игровой режим
```

Включи:

```text
Игровой режим: Вкл.
```

Игровой режим помогает Windows отдавать приоритет игровому процессу и снижать влияние некоторых фоновых задач во время игры.

Оставь его включённым на большинстве игровых ПК и ноутбуков. Отключай для проверки только в том случае, если конкретная игра стабильно работает хуже с ним; сравнивай одну и ту же сцену.

## Режим питания

Открой:

```text
Параметры → Система → Питание и батарея
```

Для настольного ПК начни с:

```text
Режим питания: Максимальная производительность
```

Затем сравни энергопотребление в простое, температуру и шум вентиляторов. Оставляй более производительный режим, только если он полезен для твоей нагрузки; на простаивающем ПК он может увеличить энергопотребление без улучшения игр.

Для ноутбука:

- играй при подключённом адаптере питания;
- выбери производительный режим в Windows и, если доступно, в утилите производителя ноутбука;
- учитывай, что более высокий режим питания увеличивает нагрев, шум и расход батареи.

Используй [меню диагностики без изменений](09-powershell-diagnostics.html), чтобы проверить активные и доступные схемы электропитания.

> **Примечание:** «Максимальная производительность» не гарантирует более высокий FPS. На современных ПК эффект может быть небольшим или отсутствовать, а потребление в простое и температура могут вырасти. Проверь результат вместо выбора режима только по названию.

## Параметры графики Windows

Открой:

```text
Параметры → Система → Дисплей → Графика
```

Здесь можно назначить приложениям конкретный GPU и включить системные игровые параметры.

### Назначение высокопроизводительной видеокарты

Это особенно актуально для ноутбуков и систем с несколькими GPU.

1. В разделе пользовательских настроек приложений найди игру.
2. Если её нет в списке, выбери `Обзор` и добавь файл `.exe` игры.
3. Нажми `Параметры`.
4. Выбери:

   ```text
   Высокая производительность
   ```

5. Сохрани изменения.

> **Совет:** на ноутбуках предпочтительный GPU также можно выбрать в NVIDIA Control Panel, AMD Software или утилите производителя. Не создавай конфликтующие профили без необходимости.

## Оптимизация для игр в оконном режиме

Открой:

```text
Параметры → Система → Дисплей → Графика → Изменить параметры графики по умолчанию
```

Найди:

```text
Оптимизация для игр в оконном режиме
```

Параметр действует на современных играх в оконном режиме или без рамки в Windows 11 версии 22H2 и новее. После изменения может потребоваться перезапустить игру, а иногда и Windows.

### Как проверить

1. Выбери один режим.
2. Перезагрузи ПК, если Windows этого требует.
3. Проверь одну и ту же сцену игры.
4. Сравни FPS, время кадра, задержку и поведение в полноэкранном режиме.
5. Оставь настройку с лучшим результатом на твоей системе.

## Аппаратное планирование GPU

Аппаратное ускорение планирования GPU (HAGS) находится в том же разделе:

```text
Параметры → Система → Дисплей → Графика → Изменить параметры графики по умолчанию
```

Найди:

```text
Аппаратное ускорение планирования GPU
```

HAGS — необязательный параметр для проверки, а не рекомендация включать его всем.

1. Запиши исходный результат в одной повторяемой игровой сцене.
2. Включи HAGS.
3. Перезагрузи ПК.
4. Повтори тест с теми же настройками и оверлеями.
5. Сравни 1% low, время кадра, стабильность и новые подёргивания.
6. Оставь настройку только при повторяемом улучшении и отсутствии новых проблем. Иначе отключи её и снова перезагрузи ПК.

HAGS требует совместимых видеокарты и драйвера. Для некоторых функций, в том числе отдельных реализаций генерации кадров, он может быть необходим. Проверяй актуальную документацию производителя видеокарты.

Microsoft описывает HAGS как перенос большей части планирования GPU на выделенный графический процессор планирования; для большинства пользователей переход должен быть незаметен. См. [блог Microsoft DirectX](https://devblogs.microsoft.com/directx/hardware-accelerated-gpu-scheduling/).

> **Важно:** HAGS не является обязательным способом повысить FPS. Результат зависит от видеокарты, драйвера, игры и версии Windows. Решение принимай по собственным измерениям.

## VRR, Auto HDR и HDR

### Переменная частота обновления

VRR может быть полезна на мониторах с FreeSync, G-SYNC Compatible или похожей технологией.

Проверь, что:

- Adaptive Sync включён в экранном меню монитора;
- VRR включён в панели управления драйвера видеокарты;
- нет мерцания и проблем в конкретных играх.

### Auto HDR и HDR

Используй HDR или Auto HDR, если монитор поддерживает HDR приемлемого качества и результат тебе нравится.

HDR может улучшить изображение в подходящих играх, но не является настройкой производительности. При проблемах с цветом, яркостью или совместимостью сначала отключи HDR для проверки.

## Частота обновления монитора

Открой:

```text
Параметры → Система → Дисплей → Расширенный дисплей
```

В списке частоты обновления выбери максимальное стабильное значение, которое поддерживают монитор, кабель и видеокарта.

Например:

```text
Монитор 165 Hz должен быть настроен в Windows на 165 Hz, а не на 60 Hz.
```

> **Предупреждение:** не путай FPS и Hz. FPS — число кадров, которое выводит ПК, а Hz — число обновлений монитора в секунду. Важны оба показателя, но это не одно и то же.

## Уведомления и режим «Не беспокоить»

Уведомления отвлекают и иногда запускают дополнительные оверлеи.

Открой:

```text
Параметры → Система → Уведомления
```

- Отключи уведомления ненужных приложений.
- Используй режим «Не беспокоить» во время игры.
- Отключи рекламные уведомления и рекомендации, если они не нужны.

Это напрямую не повышает FPS, но уменьшает число отвлечений во время игры.

## Оверлеи и запись

Оверлеи полезны, но несколько одновременно работающих инструментов могут конфликтовать, создавать нагрузку или вызывать проблемы в игре.

Проверь, нужны ли тебе:

- Xbox Game Bar;
- оверлей Discord;
- NVIDIA Overlay;
- AMD Overlay;
- оверлей Steam;
- Overwolf;
- OBS Game Capture или запись;
- оверлеи мониторинга и FPS.

Не отключай всё навсегда. Оставь нужные функции. Если появятся подёргивания, сбои или нестабильное время кадра, временно отключай оверлеи по одному и повторно проверяй ту же игру.

> **Совет:** MSI Afterburner с RTSS подходит для мониторинга. Если в конкретной игре возникли проблемы, проверь её также с отключённым оверлеем RTSS.

## Приложения автозагрузки

Открой:

```text
Диспетчер задач → Автозагрузка приложений
```

Отключи приложения, которые не нужны сразу после загрузки Windows.

Часто можно отключить, если они не нужны постоянно:

- игровые лаунчеры;
- мессенджеры;
- обновляторы Adobe, Google или Office;
- клиенты облачных сервисов;
- RGB-программы;
- средства записи и оверлеи;
- ненужные автообновляторы.

Не отключай вслепую:

- компоненты аудиодрайвера;
- компоненты тачпада, горячих клавиш или питания ноутбука;
- ПО управления вентиляторами, если ты его используешь;
- ПО мыши или клавиатуры, если от него зависят профили;
- программу безопасности, если это единственный активный антивирус.

## Визуальные эффекты Windows

Найди через поиск Windows:

```text
Настройка представления и производительности Windows
```

Можно отключить некоторые анимации, чтобы упростить интерфейс и повысить его отзывчивость.

На современных ПК это редко заметно влияет на игровой FPS. Считай такую настройку вопросом удобства рабочего стола, а не основной игровой оптимизацией. Не отключай нужные элементы интерфейса ради незначительной экономии ресурсов.

## Безопасность и виртуализация

Не отключай без понятной причины:

- Microsoft Defender;
- Брандмауэр Windows;
- UAC;
- Центр обновления Windows;
- изоляцию ядра;
- VBS и связанные средства защиты.

Некоторые из этих функций могут влиять на производительность в отдельных конфигурациях, но отключение снижает безопасность и может повлиять на совместимость. Сначала выяви конкретную проблему, создай точку восстановления и оцени компромисс.

Microsoft рекомендует оставлять целостность памяти включённой, если нет конкретной и понятной причины поступить иначе. См. [Microsoft Learn](https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity).

> **Предупреждение:** не запускай `.reg`, `.bat` или PowerShell-скрипты, которые массово отключают защиту и системные функции. Большее число отключённых компонентов не означает лучшую оптимизацию.

## Полезная диагностика

Используй [меню диагностики без изменений](09-powershell-diagnostics.html), чтобы проверить схемы питания, элементы автозагрузки и процессы. Отдельные команды сохранены в руководстве по диагностике.

- [ ] Для игры назначен высокопроизводительный GPU, если в системе несколько видеокарт.
- [ ] Проверены HAGS и оптимизация для игр в оконном режиме.
- [ ] Установлена правильная частота обновления монитора.

- [ ] Отключены ненужные приложения автозагрузки.
