## Совместимость

- VAC может пометить неразрешённое стороннее ПО, взаимодействующее с процессом игры.
- Не изменяй основные файлы игры и не используй неодобренные внешние инструменты.
- Избегай сторонних оверлеев при диагностике, особенно Discord Overlay, Xbox Game Bar, NVIDIA Overlay и RTSS.
- Если ты используешь `-allow_third_party_software`, учти, что это может повлиять на Trust Factor и не требуется для обычной оптимизации.

По умолчанию используй рендерер, выбранный текущим клиентом игры. Другой доступный рендерер проверяй только по конкретной причине, связанной с совместимостью или производительностью; компиляция шейдеров и фризы могут различаться между системами и патчами.

## Настройки графики

Настройки графики влияют на FPS, чёткость картинки и видимость моделей. Начни со стабильной базы, затем меняй по одной настройке.

| Настройка | Рекомендуемый старт | Почему |
| --- | --- | --- |
| Разрешение | Родное разрешение | Лучшая чёткость; снижай, только если нужно больше FPS |
| Режим экрана | Полный экран | Обычно самый предсказуемый режим вывода |
| Boost Player Contrast | Включено | Может улучшить видимость моделей игроков |
| Wait for V-Sync | Выключено | Не добавляет задержку; VRR настраивай отдельно, если он поддерживается |
| Multisampling Anti-Aliasing | Для начала 2x MSAA | Баланс между качеством краёв и нагрузкой на GPU |
| Global Shadow Quality | Высокое | Тени могут давать полезную игровую информацию |
| Model / Texture Detail | Среднее | Разумный баланс VRAM и качества картинки |
| Shader Detail | Низкое | Снижает нагрузку на GPU при малом влиянии на соревновательную игру |
| Particle Detail | Низкое | Снижает нагрузку на CPU и GPU от эффектов |
| Ambient Occlusion | Выключено | Экономит ресурсы GPU |
| FidelityFX Super Resolution | Выключено | Используй нативный рендеринг, если не нужно больше FPS |
| NVIDIA Reflex | Включено + Boost, если поддерживается | Может снизить системную задержку на поддерживаемых GPU NVIDIA |

Если FPS низкий, снижай настройки в таком порядке:

1. Shader Detail
2. Particle Detail
3. Ambient Occlusion
4. MSAA
5. Shadow Quality

Оставляй Shadow Quality выше, если ты опираешься на информацию от теней, но проверь стоимость в FPS на привычных картах.

## Ограничение FPS и задержка

Используй внутриигровой ограничитель FPS раньше внешних.

Высокий предел вроде `fps_max 400` — частая отправная точка для CS2, потому что на современном оборудовании он обычно не ограничивает производительность:

```text
fps_max 400
```

Если подача кадров нестабильна, проверь лимит около устойчивого уровня FPS вместо неограниченного режима. Лучший лимит зависит от CPU, GPU, монитора и карты.

Для GPU NVIDIA с поддержкой Reflex:

- Включи Reflex в игре.
- Проверь варианты `On` и `On + Boost`.
- Не включай одновременно глобальный NVIDIA Low Latency Mode принудительно.

Для мониторов с VRR:

- Включи G-SYNC или FreeSync в панели управления GPU и в OSD монитора.
- Держи внутриигровой V-Sync выключенным, если не нужно настраивать поведение VRR для конкретного монитора.
- Используй лимит FPS в пределах диапазона VRR, если подача кадров неравномерна.

## Параметры запуска

Расположение конфигурации:

```text
...\steamapps\common\Counter-Strike 2\game\csgo\cfg\
```

Частые параметры запуска:

| Параметр | Назначение | Рекомендация |
| --- | --- | --- |
| `-novid` | Пропускает вступительное видео | Безопасно |
| `-nojoy` | Отключает опрос ввода с джойстика | По желанию |
| `-high` | Запрашивает высокий приоритет процесса | Только для проверки; не всегда полезен |
| `-threads <N>` | Принудительно задаёт число потоков | Избегай без конкретной причины |

Не копируй целую строку параметров запуска из видео или с форума. Добавляй по одному параметру и проверяй его.

## Сетевые настройки

CS2 сам обрабатывает большую часть сетевого поведения. Не копируй старые сетевые команды CS:GO, не понимая их.

Если у тебя потери пакетов или высокий пинг:

1. Поставь на паузу загрузки, облачную синхронизацию, торренты и стриминг.
2. По возможности используй Ethernet.
3. Перезагрузи роутер, если проблема локальная.
4. Проверь другой регион серверов.
5. Измеряй задержку до того региона серверов, где ты действительно играешь.

Базовые проверки соединения см. в разделе [Диагностика в PowerShell](../09-powershell-diagnostics.html#сеть).

## Частые проблемы

| Симптом | Первая проверка |
| --- | --- |
| Низкий FPS при занятости GPU 95–99% | Снизь шейдеры, частицы, MSAA или тени |
| Низкий FPS при загрузке одного ядра CPU | Закрой фоновые приложения и снизь настройки, нагружающие CPU |
| Фризы на новых картах | Дай шейдерам скомпилироваться, проверь файлы игры, используй SSD |
| Вялая мышь или высокая задержка | Включи Reflex, выключи V-Sync, убери оверлеи |
| Потери пакетов или высокий пинг | Проверь загрузки, Ethernet, роутер, провайдера и регион сервера |
| Сбой при запуске или ошибка VAC | Проверь файлы игры в Steam и удали неодобренное стороннее ПО |

Source 2 компилирует шейдеры динамически в начале игры. После обновления драйвера GPU или значительного изменения настроек сыграй полную тренировочную сессию или Deathmatch перед бенчмарком.

## Сценарий бенчмарка

Используй один повторяемый сценарий для каждого теста.

| Параметр | Рекомендация |
| --- | --- |
| Сцена | Карта мастерской Aim Botz или записанная соревновательная демка |
| Прогрев | 5 минут |
| Прогоны | Не менее 3 |
| Метрики | Средний FPS, 1% минимумов, 0,1% минимумов, время кадров |
| Инструменты | CapFrameX, PresentMon или HWiNFO |
| Контроль | Одно разрешение, настройки, драйвер, оверлеи и фоновая нагрузка |

Полный протокол см. в [шаблонах бенчмарка](../16-benchmark-templates.html).

## Откат

1. Удали или переименуй `autoexec.cfg`.
2. Удали пользовательские параметры запуска Steam.
3. Верни изменённые внутриигровые настройки к прежним значениям.
4. Если проблемы начались после обновления драйвера, откатись на предыдущий стабильный драйвер, прежде чем рассматривать чистую установку.
5. Перезагрузись и повтори сценарий бенчмарка.

---

## Проверка

Запиши версию игры и дату теста. Используй одну и ту же карту или демку, разрешение, настройки, драйвер, оверлеи и фоновую нагрузку минимум для трёх прогонов. Сравни FPS, 1% минимумов, время кадров, температуры и стабильность; не считай непроверенные параметры запуска и старые команды CS:GO рекомендациями.

Приведённые выше настройки — осторожные стартовые значения, а не результаты, сертифицированные для патча. Перед применением рекомендаций, чувствительных к патчу, проверь текущие пункты меню и официальные рекомендации по совместимости.
