## Совместимость с Vanguard

Vanguard — античит Riot уровня ядра. Не отключай, не изменяй и не блокируй его службы.

- Не изменяй файлы игры.
- Не используй инжекторы, читы, неподписанные драйверы или драйверы с тестовой подписью.
- Не отключай службы Vanguard.
- Если Vanguard сообщает об ошибке, следуй официальным рекомендациям поддержки Riot для этого кода ошибки.
- Некоторые оверлеи и программы мониторинга могут конфликтовать с Vanguard. Проверь с ними выключенными.

В Windows 11 для VALORANT и Vanguard могут требоваться TPM 2.0 и Secure Boot. Перед изменением настроек BIOS, TPM, Secure Boot или порядка загрузки проверь актуальные системные требования Riot. Перед такими изменениями сохрани ключ восстановления BitLocker.

## Настройки графики

Начни с этих значений, затем меняй по одной настройке.

| Настройка | Рекомендуемый старт | Почему |
| --- | --- | --- |
| Разрешение | Родное | Лучшая чёткость и предсказуемое масштабирование |
| Render Scale | 100% | Избегает размытия от внутреннего апскейла |
| Limit FPS | Проверь стабильный лимит | Улучшает равномерность времени кадров |
| V-Sync | Выключено | Не добавляет задержку; VRR настраивай отдельно, если он поддерживается |
| Multithreaded Rendering | Включено | Может улучшить использование CPU |
| Material Quality | Низкое или среднее | Снижает нагрузку на GPU |
| Texture Quality | Низкое или среднее | Зависит от доступной VRAM |
| Detail Quality | Низкое | Снижает нагрузку на GPU |
| UI Quality | Низкое | Снижает нагрузку на GPU |
| Vignette | Выключено | Убирает эффект, не дающий игровой пользы |
| Bloom | Выключено | Снижает нагрузку на GPU |
| Distortion | Выключено | Снижает нагрузку на GPU |
| First Person Shadows | Выключено | Снижает нагрузку на GPU |

Если FPS низкий, снижай настройки в таком порядке:

1. Detail Quality
2. Material Quality
3. Texture Quality
4. Vignette, Bloom и Distortion
5. First Person Shadows

## Ограничение FPS и задержка

Используй внутриигровой ограничитель FPS раньше внешних.

Практичная отправная точка — лимит немного выше частоты обновления монитора. Если подача кадров нестабильна, проверь лимит на уровне, который твоя система держит во время схваток.

Для GPU NVIDIA с поддержкой Reflex:

- Включи Reflex Low Latency в игре.
- Проверь варианты `On` и `On + Boost`.
- Не включай одновременно глобальный NVIDIA Low Latency Mode принудительно.

Для GPU AMD:

- Проверь AMD Anti-Lag в профиле драйвера для игры.
- Не включай несколько связанных с задержкой функций драйвера одновременно.

Для мониторов с VRR:

- Включи G-SYNC или FreeSync в панели управления GPU и в OSD монитора.
- Держи внутриигровой V-Sync выключенным, если не нужно настраивать поведение VRR.
- Установи лимит FPS в пределах диапазона VRR, если подача кадров неравномерна.

Проверь Raw Input Buffer отдельно. Оставляй его, только если поведение мыши и время кадров остаются стабильными.

## Параметры запуска

У VALORANT мало документированных параметров запуска. Предпочитай внутриигровые настройки.

Не копируй параметры запуска из других игр, особенно `-high`, `-threads` и устаревшие параметры Unreal Engine. Добавляй по одному параметру, только если он описан Riot или другим надёжным источником.

## Частые проблемы

| Симптом | Первая проверка |
| --- | --- |
| Ошибка Vanguard или сбой инициализации | Проверь статус Riot, службы Vanguard, TPM 2.0 и требования Secure Boot |
| Код ошибки VAN | Найди точный код в официальной документации поддержки Riot |
| Низкий FPS при ненагруженной GPU | Проверь настройки, нагружающие CPU, фоновые приложения и загрузку отдельных ядер |
| Высокая задержка ввода | Включи Reflex, выключи V-Sync, убери оверлеи, проверь лимит FPS |
| Скачки сети | Поставь на паузу загрузки, используй Ethernet, проверь регион сервера Riot и маршрутизацию |
| Сбой после изменения настроек | Верни настройки видео по умолчанию и удали пользовательские параметры запуска |

## Сценарий бенчмарка

Используй один повторяемый сценарий для каждого теста.

| Параметр | Рекомендация |
| --- | --- |
| Сцена | Тир (The Range) с фиксированным числом ботов и маршрутом или пользовательская игра с ботами |
| Прогрев | 3–5 минут |
| Прогоны | Не менее 3 |
| Метрики | Средний FPS, 1% минимумов, 0,1% минимумов, время кадров, занятость GPU, температуры |
| Контроль | Одна карта, настройки, драйвер, оверлеи и фоновая нагрузка |

Полный протокол см. в [шаблонах бенчмарка](../16-benchmark-templates.html).

## Проверка

Запиши версию игры и дату теста. Используй одну и ту же карту или маршрут в тире, настройки, драйвер, оверлеи и фоновую нагрузку минимум для трёх прогонов. Сравни время кадров, FPS, температуры и стабильность; субъективное ощущение ввода записывай отдельно от измеренной задержки.

Перед изменением параметров безопасности системы проверь актуальные рекомендации Riot по Vanguard, Secure Boot, TPM и настройкам, чувствительным к патчу.

## Откат

1. Сбрось внутриигровые настройки видео по умолчанию.
2. Удали пользовательские параметры запуска в Riot Client.
3. Верни настройки Reflex, Anti-Lag и VRR к прежним значениям.
4. Если проблемы начались после обновления драйвера, откатись на предыдущий стабильный драйвер.
5. Перезагрузись и повтори сценарий бенчмарка.
