# Системные утилиты

В этом разделе собраны полезные системные утилиты для диагностики и оптимизации игровых ПК.

## RAMMap от Microsoft Sysinternals

[RAMMap](https://learn.microsoft.com/en-us/sysinternals/downloads/rammap) - это мощный инструмент от Microsoft Sysinternals, который показывает, как именно используется оперативная память в вашей системе. Он полезен для диагностики проблем с памятью и понимания того, какие процессы занимают больше всего памяти.

### Важные возможности:

- Показывает распределение памяти по типам (Free, Standby, Modified, Active, etc.)
- Отображает содержимое кэша памяти
- Определяет процессы, использующие память в различных категориях
- Поддерживает инструменты очистки памяти

### Рекомендации по использованию:

1. Запустите RAMMap от имени администратора
2. Изучите вкладку "Memory Addresses" для понимания использования памяти
3. Обратите внимание на размеры различных категорий памяти
4. Используйте кнопку "Clear" при необходимости освободить кэши

## Mem Reduct

Mem Reduct — бесплатная программа, которая помогает освобождать оперативную память, удаляя ненужные данные из кэша и освобождая память для других процессов.

### Основные особенности:

- Автоматическое освобождение памяти
- Пользовательский интерфейс с реальным временем отображения (Real-time view)
- Уведомления о количестве освобожденной памяти
- Поддержка различных уровней автоматизации

### Рекомендации по использованию:

1. Запустите Mem Reduct в фоне
2. Наблюдайте за показаниями в интерфейсе
3. Установите нужные параметры автозапуска
4. Пересмотрите политики очистки при возникновении проблем с памятью

## Дополнительные утилиты:

Если вы ищете больше инструментов для оптимизации, обратите внимание на:

- **Process Explorer** от Microsoft Sysinternals
- **DiskMon** для наблюдения за операциями с диском  
- **Wireshark** для анализа сетевого трафика

Эти утилиты могут быть полезны в рамках диагностики проблем производительности.

## Где найти эти утилиты:

- **RAMMap**: Доступен на [сайте Microsoft Sysinternals](https://learn.microsoft.com/en-us/sysinternals/downloads/rammap)
- **Mem Reduct**: Доступен на [https://www.memreduct.com/](https://www.memreduct.com/)

Обе утилиты помогут диагностировать использование памяти и выявить узкие места в производительности игрового ПК.
