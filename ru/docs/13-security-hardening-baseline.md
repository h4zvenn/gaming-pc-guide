Цель — поддерживать реальную безопасность с минимальным влиянием на FPS, сохраняя совместимость с играми, античитами и обновлениями.

## Принципы

1. Оставляй параметры безопасности включёнными по умолчанию, если нет измеренного и подтверждённого влияния.
2. Меняй по одной настройке и сравнивай результаты до и после.
3. Предпочитай точечные исключения вместо отключения основных средств защиты.
4. Скачивай драйверы, программы и прошивки из официальных источников.

| Компонент | Рекомендуемое состояние |
| --- | --- |
| Defender | Включён |
| Брандмауэр | Включён |
| Центр обновления Windows | Включён, обновления устанавливаются регулярно |
| UAC | По умолчанию или выше |
| Случайные скрипты | По умолчанию заблокированы |

## Учётная запись и доступ

- Используй учётную запись Microsoft или локальную учётную запись с надёжным уникальным паролем.
- Включи Windows Hello или PIN-код, если они доступны.
- Оставь UAC на уровне по умолчанию или выше.
- По возможности не используй учётную запись администратора для повседневных задач.

Чтобы проверить группы учётной записи и состояние безопасности, используй пункт 5 [руководства по диагностике без изменений](09-powershell-diagnostics.html).

## Базовая защита Defender

Оставь включёнными:

- защиту Microsoft Defender в реальном времени;
- облачную защиту;
- защиту от подмены настроек (Tamper Protection).

Добавляй точечные исключения для конкретной папки игры или процесса только при подтверждённом ложном срабатывании либо измеримой проблеме.

## Базовая настройка брандмауэра

- Оставь Брандмауэр Защитника Windows включённым для профилей доменной, частной и общедоступной сети.
- Не отключай брандмауэр целиком для устранения проблем с сетевой игрой.
- Создавай узкие правила для входящих подключений, только если они нужны игре или серверному инструменту.

## Обновления

- Оставь Центр обновления Windows включённым.
- Регулярно устанавливай накопительные обновления и исправления безопасности.
- Обновляй драйверы GPU, чипсета и сети только с сайтов производителей.
- Обновляй BIOS материнской платы или прошивку SSD, только если список изменений относится к твоей проблеме или исправляет известную ошибку.

Меню диагностики также проверяет Defender, профили брандмауэра и службу Windows Update, не меняя их состояние.

## Загрузки и управление приложениями

- Скачивай модификации и инструменты только из надёжных источников.
- Если доступно, проверяй подписи или хеши важных инструментов.
- Избегай пакетов-оптимизаторов с непонятными исполняемыми файлами, скриптами или изменениями реестра.

Пример проверки цифровой подписи:

```powershell
Get-AuthenticodeSignature "C:\Path\To\file.exe" |
Select-Object Status, SignerCertificate
```

## Безопасность браузера и лаунчеров

- Поддерживай браузер и игровые лаунчеры в актуальном состоянии.
- Удали ненужные расширения браузера.
- Включи двухфакторную аутентификацию для игровых аккаунтов, например Steam, Microsoft и Epic.

## Защита от программ-вымогателей и резервные копии

- Регулярно копируй сохранения игр, конфигурации и документы.
- Рассмотри контролируемый доступ к папкам, если локально хранятся важные данные.
- Периодически проверяй, что резервную копию можно восстановить.

## Проверка безопасности после настройки

После оптимизации проверь, что:

- Defender по-прежнему включён;
- брандмауэр по-прежнему включён;
- служба Windows Update не отключена;
- не появились неизвестные элементы автозагрузки, службы или запланированные задачи.

Чтобы проверить элементы автозагрузки и запланированные задачи, используй пункт 5 [меню диагностики](09-powershell-diagnostics.html). Оно не отключает и не меняет их.

## Безопасная проверка исключений

Если кажется, что защита влияет на производительность:

1. Воспроизведи проблему в повторяемом бенчмарке.
2. Проверь активность процессов и файлов; не отключай защиту первым шагом.
3. Добавь минимальное исключение с ограниченной областью действия.
4. Повторно проверь FPS, 1% low, время кадра и стабильность.
5. Запиши причину и параметры исключения.

## Не отключай глобально

Не отключай ради «оптимизации»:

- Microsoft Defender и его модули защиты;
- Брандмауэр Защитника Windows;
- UAC;
- SmartScreen;
- Центр обновления Windows.

Если у игры возникла проблема совместимости, используй точечное исключение и сохрани основные средства защиты включёнными.
