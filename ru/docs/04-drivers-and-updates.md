Драйверы и обновления не дают «магический FPS», но обеспечивают совместимость, исправления ошибок, стабильность и корректную работу оборудования. Используй официальные источники, а не сборники драйверов, «ускорители» или случайные ссылки.

## Главное правило

Скачивай драйверы только с официальных сайтов:

- производителя материнской платы или ноутбука;
- AMD;
- NVIDIA;
- Intel;
- Microsoft;
- производителя SSD, Wi-Fi-адаптера или периферийного устройства.

> **Предупреждение:** не используй Driver Booster, DriverPack, программы автоматического обновления драйверов и сайты с переупакованными драйверами. Они могут установить неподходящую версию, рекламное ПО или нестабильные компоненты.

## Рекомендуемый порядок обновления

Для чистой установки Windows или нового ПК используй такую последовательность:

1. Установи обновления Windows.
2. Установи драйвер чипсета.
3. Установи драйвер видеокарты.
4. При необходимости установи драйверы LAN/Wi-Fi/Bluetooth и аудио.
5. Устанавливай драйверы периферии только для используемых устройств.
6. Перезагрузи ПК.
7. Проверь стабильность и версии драйверов.

Если система уже настроена и работает стабильно, не нужно переустанавливать всё с нуля. Обновляй только компонент, для которого есть конкретная причина.

### Быстрый выбор

| Ситуация | Что делать |
| --- | --- |
| Свежая установка Windows | Последовательно выполни все шаги обновления |
| Стабильная настроенная система | Обнови только компонент, для которого известно об исправлении проблемы |
| Новая игра не запускается | Сначала попробуй последнюю стабильную версию драйвера GPU |

## 1. Центр обновления Windows

Открой:

```text
Параметры → Центр обновления Windows
```

Нажми:

```text
Проверить наличие обновлений
```

Установи обычные накопительные обновления и перезагрузи ПК, если Windows этого требует.

### Что устанавливать осторожно

Необязательные обновления и драйверы из Центра обновления Windows не всегда являются лучшим вариантом для видеокарты, чипсета или устройств конкретного производителя.

Проверь версию и источник перед установкой, особенно если:

- текущий драйвер работает стабильно;
- у тебя ноутбук с управлением питанием от производителя;
- обновление предлагается как необязательный драйвер;
- недавно возникали проблемы с видеодрайвером.

> **Примечание:** не отключай Центр обновления Windows навсегда ради «оптимизации». Обновления содержат исправления безопасности, стабильности и совместимости. Необязательные драйверы из Windows Update не всегда предпочтительнее драйверов производителя; перед установкой проверь источник, особенно если текущий драйвер GPU или чипсета работает стабильно.

## 2. Драйвер чипсета

Драйвер чипсета важен для управления питанием, PCIe, USB, контроллерами и взаимодействием платформы с ОС.

### Где скачать

- Для платформы AMD — на официальном сайте AMD или странице поддержки материнской платы/ноутбука.
- Для платформы Intel — на официальном сайте Intel или странице поддержки материнской платы/ноутбука.

### Как установить

1. Скачай драйвер для своей ОС и платформы.
2. Закрой ненужные приложения.
3. Запусти установщик.
4. Заверши установку.
5. Перезагрузи ПК.

> **Совет:** для ноутбуков сначала проверь страницу поддержки производителя. Там могут быть адаптированные драйверы для управления питанием, переключения графики, горячих клавиш или охлаждения.

## 3. Драйвер видеокарты

### NVIDIA

Используй NVIDIA App или страницу загрузки драйверов NVIDIA.

Выбирай драйвер с учётом:

- модели видеокарты;
- версии Windows;
- типа нагрузки: Game Ready или Studio.

Для большинства игровых ПК подходит Game Ready Driver. Studio Driver может быть предпочтительнее для рабочих приложений, монтажа и 3D-задач.

### AMD Radeon

Скачай AMD Software: Adrenalin Edition с официального сайта AMD.

Выбери драйвер для своей серии Radeon и версии Windows.

### Intel Arc и встроенная графика Intel

Используй Intel Graphics Software или официальный Intel Download Center.

Если на ноутбуке появились проблемы с яркостью, гибридной графикой или выходом из сна, сначала попробуй драйвер производителя ноутбука.

## 4. Нужно ли немедленно устанавливать новый драйвер GPU

Не всегда.

Обнови драйвер, если:

- новой игре нужна последняя версия;
- в списке изменений есть исправление твоей проблемы;
- возникают ошибки, вылеты, артефакты или проблемы совместимости;
- драйвер добавляет нужную технологию;
- ты переустанавливаешь Windows.

Оставь текущую версию, если:

- система работает стабильно;
- ты не играешь в недавно вышедшую игру с новым профилем Game Ready;
- известно, что новая версия проблемна для твоей конфигурации;
- ПК используется для важных задач, где стабильность важнее новизны.

> **Важно:** более новый драйвер не всегда быстрее в каждой игре. Сравнивай результаты в своих играх и при необходимости возвращайся к известной стабильной версии.

## 5. Чистая установка драйвера GPU

Обычного обновления обычно достаточно.

Чистая установка может понадобиться при таких симптомах:

- частые сбои графического драйвера;
- чёрный экран или артефакты после обновления;
- некорректная работа настроек панели управления драйвером;
- игра не запускается из-за конфликта со старым компонентом;
- ты сменил производителя видеокарты (AMD ↔ NVIDIA ↔ Intel).

### Сначала попробуй простой способ

Для NVIDIA выбери в установщике вариант чистой установки, если он доступен. Для AMD используй Factory Reset только если понимаешь, что настройки драйвера будут сброшены.

### DDU — только при реальной необходимости

Display Driver Uninstaller полностью удаляет драйверы видеокарты. Это может помочь при серьёзных конфликтах, но не требуется перед каждым обновлением.

Если используешь DDU:

1. Создай точку восстановления.
2. Заранее скачай нужный пакет драйвера.
3. Прочитай инструкцию к инструменту.
4. Не используй его для обычных обновлений без конкретной проблемы.
5. После очистки установи драйвер из официального источника.

> **Предупреждение:** не запускай DDU каждый месяц «ради FPS». Частое полное удаление драйверов не является оптимизацией.

### Как откатить драйвер GPU

1. Открой Диспетчер устройств, выбери видеокарту и на вкладке `Драйвер` нажми `Откатить`, если кнопка доступна.
2. Если откат недоступен, установи предыдущий официальный пакет драйвера производителя.
3. Если оба способа недоступны, а проблема появилась после обновления драйвера, используй DDU, как описано выше.
4. Не совмещай откат и чистую установку в один шаг без повторной проверки проблемной игры.

## 6. Драйверы материнской платы и ноутбука

На странице поддержки модели обычно доступны:

- LAN/Ethernet;
- Wi-Fi;
- Bluetooth;
- аудио;
- SATA/RAID;
- утилиты BIOS;
- приложения управления вентиляторами, подсветкой и питанием.

Устанавливай только нужное.

Например:

- если используешь Ethernet, драйвер Wi-Fi может быть не нужен;
- если подсветка RGB не нужна, тяжёлый пакет для неё необязателен;
- если ПО производителя постоянно использует CPU/RAM или вызывает ошибки, сначала отключи его автозапуск, не удаляя нужные драйверы.

> **Совет:** драйвер и утилита производителя — не одно и то же. Драйверы сети и аудио часто необходимы; большие пакеты для оверлеев, телеметрии и подсветки могут быть необязательны.

## 7. Драйверы и прошивка SSD

### Драйверы NVMe/SATA

В большинстве случаев стандартные драйверы хранения Microsoft работают нормально. Не устанавливай отдельные драйверы контроллера без конкретной причины или рекомендации производителя.

### Прошивка SSD

Обновление прошивки SSD полезно, если производитель указывает исправления для:

- стабильности;
- потери данных;
- поведения при переходе в сон и выходе из него;
- перегрева;
- совместимости;
- производительности в конкретном сценарии.

Перед обновлением прошивки SSD:

1. Сделай резервную копию важных данных.
2. Прочитай инструкцию производителя.
3. Подключи ноутбук к адаптеру питания.
4. Не выключай питание во время обновления.

## 8. Проверка драйверов в Windows

### Диспетчер устройств

1. Нажми `Win + X`.
2. Открой `Диспетчер устройств`.
3. Проверь, нет ли устройств с жёлтым предупреждающим значком.
4. Открой свойства нужного устройства → вкладка `Драйвер`.

Для проверки версии драйвера GPU и сборки Windows используй [меню диагностики без изменений](09-powershell-diagnostics.html). Отдельные команды PowerShell сохранены в руководстве по диагностике.

## 9. Необязательное ПО производителей

Перед установкой спроси себя: «Какую конкретную пользу даст эта программа?»

Часто необязательны:

- автоматические обновляторы драйверов;
- «игровые оптимизаторы»;
- дублирующие оверлеи;
- очистители RAM;
- постоянно работающие программы телеметрии;
- пакеты RGB, если управление подсветкой не нужно;
- предустановленные пробные антивирусы.

Могут быть необходимы:

- управление режимом питания ноутбука;
- настройка вентиляторов;
- горячие клавиши;
- профили тачпада;
- переключение между встроенной и дискретной графикой;
- обновление прошивки периферийных устройств.

Не удаляй программу, пока не поймёшь её роль. Сначала отключи автозапуск и проверь работу системы.

## Контрольный список

- [ ] Обновления Windows установлены.
- [ ] Драйвер чипсета установлен из официального источника.
- [ ] Установлен стабильный драйвер видеокарты.
- [ ] В Диспетчере устройств нет устройств с жёлтым предупреждающим значком.
- [ ] Не использовались сборники драйверов и сомнительные автообновляторы.
- [ ] Чистая установка драйвера выполнялась только при реальной проблеме.
- [ ] Прошивка SSD обновлялась только при наличии причины и по инструкции производителя.
- [ ] Необязательные утилиты не работают в фоне без необходимости.

## Итог

Стабильная исходная конфигурация важнее погони за каждой новой версией. Используй официальные драйверы, обновляй компоненты осознанно, выполняй чистую установку только при необходимости и не устанавливай лишние программы-помощники.
