# Downloads

This directory contains downloadable resources for PC gaming optimization. All materials are designed to be safe, tested, and useful for users following the optimization methodology outlined in this guide.

## Structure

- `checklists/` - Checklists for various optimization tasks
- `templates/` - Templates for recording performance data  
- `configs/` - Verified game configurations tested on real hardware

## Usage Guidelines

All files in this directory are meant to be used by readers of the documentation. They should not contain personal or proprietary tools that change system settings.

- Checklists: Use before starting any optimization work
- Templates: Document your optimization process and results  
- Configurations: Use as starting points for game settings
