# Safe Optimization Checklist

## Before You Start

- [ ] Create a Windows system restore point
- [ ] Document current baseline performance (FPS, frame times)
- [ ] Check system temperatures and stability
- [ ] Verify free disk space (at least 15% on system drive)
- [ ] Ensure you have the BitLocker recovery key if needed

## System Preparation

- [ ] Update all drivers to latest stable versions
- [ ] Run Windows Update
- [ ] Check for malware with Windows Defender or other antivirus
- [ ] Disable unnecessary startup programs and services
- [ ] Close all background applications

## Optimization Process

- [ ] Make only one change at a time
- [ ] Test each change thoroughly before applying the next
- [ ] Record performance impact of each change
- [ ] Monitor system stability during testing
- [ ] Keep detailed notes about what was changed and when

## Safety Measures

- [ ] Have rollback procedures ready
- [ ] Verify that changes don't affect game compatibility
- [ ] Check for any WHEA errors or system crashes
- [ ] Ensure all hardware is within safe operating limits
- [ ] Test with different games to verify consistency

## Documentation

- [ ] Document each change in a separate log file
- [ ] Include before/after performance comparisons
- [ ] Note any issues or anomalies encountered
- [ ] Save screenshots of settings for reference
- [ ] Update the optimization journal regularly

This checklist should be followed for every optimization step to ensure system stability and prevent unintended consequences.
